# Security Policy

Please do not publish an exploitable vulnerability in a public issue.

Report security problems privately to `security@kwickboot.com`. Include the
affected version, reproduction steps, impact and any suggested mitigation. Do
not include production credentials or personal data.

We will acknowledge a report, investigate it and coordinate disclosure with the
reporter. Supported releases and signing status are documented on
[kwickboot.com/security](https://kwickboot.com/security/) and in
[CODE_SIGNING.md](CODE_SIGNING.md).
